# Changelog

## 0.1.0 (2026-11-16)

- First release.
- Case format with hops, bridges, swaps, balances, funding, events and orders; per-network address and hash checks.
- Stolen-first tracing with traced amounts per hop and per address.
- Checks FR-ORIGIN, FR-PATH, FR-TARGET, FR-CUSTODIAL, FR-BALANCE, FR-ORDER, FR-PARTICULARITY, FR-REPORTED, FR-ISSUER.
- Issuer and law-enforcement copies as JSON and Markdown with a SHA-256.
- Published freeze policies for Circle, Paxos and Tether with sources.
