# Security

Report a vulnerability privately through GitHub's "Report a vulnerability" button on this repository (Security tab). Please do not open a public issue for it.

In scope: the freezereq package, its CLI and its examples. Out of scope: issuers' systems, blockchains and explorers.

Things worth a private report:

- A case that makes the tracing report more traced funds than entered the chain.
- A way to get victim details into the issuer copy.
- A crash or hang on malformed input.
